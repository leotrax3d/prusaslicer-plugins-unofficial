Builds a plate with a word that stays readable when you turn it around, by overlaying the word with its own 180° rotation, or with a second word.

### How to use it
1. Run **Plugins → Generators → Ambigram**.
2. Enter a word. Optionally enter a second word, for example a pair of names.
3. Choose a font, the text height and depth, and whether you want a base plate or a keyring hole.
4. Slice and print. It prints flat, without supports.

### Choosing a word
- **Short words work best:** four to six letters.
- **Heavy, wide fonts** overlap better than thin ones.
- Letters like **H N O S X Z** look the same upside down; **b/q, d/p, n/u, M/W** swap into each other. Words built from them read best.
- Try a few fonts. The dialog only takes seconds.

### Good to know
- **Mirror instead of Rotate** makes it read in a mirror instead.
- A colour change at the top of the base plate makes the letters stand out.
- This is an overlay ambigram. Sculptures that show a different word from the front and the side need boolean intersection, which the plugin API does not offer.
